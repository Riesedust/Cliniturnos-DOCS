# CliniTurnos 💉🏥

Sistema de gestión de turnos médicos (proyecto académico grupal).

**Stack:** Angular · Django REST Framework · MySQL · Docker (nginx + Gunicorn)

## Repositorios

Este repo orquesta el proyecto completo para ejecutarlo con Docker.
El código fuente vive en:

- **Backend (Django REST Framework):** https://github.com/MalenaCerrud0/CliniTurnos_BACKEND
- **Frontend (Angular):** https://github.com/BauuRuiz29/CliniTurnos-FRONTEND

## Ejecutar
```bash
git clone <link-repo-principal>
cd <nombre-repo>
docker compose up --build
```

La app queda en http://localhost:8000

Para detener: `docker compose down`
